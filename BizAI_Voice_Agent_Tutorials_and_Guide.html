🟢 PART 2: Step-by-Step Hands-On Setup Guide (Vapi.ai)

1 Create Account & Assistant
Go to vapi.ai ➔ Select Assistants ➔ Click Create Assistant.

2 Set Prompt & Persona
Name: BizAI Front Desk
Model: GPT-4o
Voice Engine: ElevenLabs ➔ Voice: Rachel or Sarah.
Paste the System Prompt below:

You are Sarah, the AI Front Desk Receptionist for BizAI Center in Memphis, TN.
Your job is to answer incoming calls, explain our 6 core services (AI Voice Agents, Business Startup, Bookkeeping, Business Support, Administrative Applications, and Newcomer Services), answer caller questions, and book consultation meetings.

RULES:
1. Speak in short, human sentences (maximum 2-3 sentences per turn).
2. Ask for the caller's Name, Email, and Phone Number before booking.
3. Be professional, clear, and welcoming.

3 Upload Knowledge Base Documents (RAG)
Upload your company's PDFs (Services Overview, Pricing, FAQs) under the Files tab so the agent can accurately answer detailed questions.

4 Link Phone Number & Automate Lead Logging
Buy a local phone number (area code 901) under the Phone Numbers tab. Route incoming calls to BizAI Front Desk, and connect a webhook URL to https://www.bizai.center/api/consultation or Make.com to email leads to info@bizai.center.

🔵 PART 3: Advanced Engineering (Custom Code Pipeline)

For custom developers who want to own the real-time audio pipeline (< 500ms latency):

// Real-time audio stream pipeline (Node.js & WebSockets)
import WebSocket from 'ws';
import { createClient } from '@deepgram/sdk';

const deepgram = createClient(process.env.DEEPGRAM_API_KEY);
const dgLive = deepgram.listen.live({
  model: 'nova-2-phonecall',
  language: 'en-US',
  encoding: 'mulaw',
  sample_rate: 8000
});

// Process incoming audio and generate streaming voice output
dgLive.on('transcriptReceived', async (data) => {
  const userSpeech = data.channel.alternatives[0].transcript;
  if (data.is_final && userSpeech.trim()) {
    const aiResponse = await queryOpenAIGPT4(userSpeech);
    streamTTSToCaller(aiResponse);
  }
});
